# 05 · Ciberseguretat

En aquesta àrea estudiaré els principis de ciberseguretat, la gestió del risc, la protecció de sistemes, la detecció d'incidents i les bones pràctiques defensives.

Hi guardaré apunts, exercicis de laboratori autoritzat, anàlisis de casos, llistes de comprovació, configuracions defensives i documentació de conceptes clau.

> Les pràctiques es limitaran sempre a sistemes propis, entorns de laboratori o sistemes amb autorització explícita.
